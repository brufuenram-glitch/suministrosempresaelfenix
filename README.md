# Soluciones Empresariales El Fénix

Sitio web corporativo y de alta conversión B2B para **Soluciones Empresariales El Fénix**, especializada en la venta y personalización de artículos promocionales y regalos corporativos para empresas en México.

## 🚀 Tecnologías Utilizadas

- **HTML5 Semántico**
- **CSS3 Vanilla** (Sistema de diseño con paleta Blanco/Negro/Gris y acento en Amarillo Fénix `#F59E0B`)
- **Vanilla JavaScript** (Carruseles interactivos, navegación scrollspy, procesador de cotización y menú responsive)
- **Sin Frameworks ni Dependencias**: Funciona abriendo directamente `index.html` en cualquier navegador.

## 📁 Estructura del Proyecto

```
.
├── index.html          # Estructura HTML5 completa
├── styles.css          # Estilos y sistema de diseño CSS3
├── script.js            # Lógica interactiva en JS puro
├── README.md           # Documentación del proyecto
└── assets/
    └── images/         # Imágenes fotorrealistas de producto
```

## 🌐 Despliegue

Sitio optimizado para desplegarse fácilmente en **Vercel**, GitHub Pages o cualquier hosting estático.
